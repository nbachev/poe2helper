# PoE2 Helper

Оверлей для Path of Exile 2: оценка предмета на торговой площадке по хоткею —
и автоматический пересчёт тиров итем-фильтра NeverSink по актуальным ценам.

```
Ctrl+D над предметом  →  оверлей с модами  →  снял лишнее  →  цена
Вкладка «Итем-фильтр» →  цены с poe.ninja   →  тиры пересчитаны
```

---

## Что умеет

**Оценка предмета**

* Глобальный хоткей (по умолчанию `Ctrl+D`): наводишь курсор на предмет в игре — открывается оверлей.
* Каждый мод — отдельная строка с галочкой и полями «мин/макс». Снимаешь лишние моды, правишь границы.
* **Добавление своего мода из пула** — кнопка «＋ Мод из пула». Ищет по всему списку модов торговой площадки (несколько тысяч), включая те, которых на предмете нет. Моды с вариантами («Allocates …») подставляются вариантом.
* Фильтры предмета: редкость, база, iLvl, качество, сокеты, corrupted, онлайн/все.
* Результат: список лотов с ценами, минимум и медиана, кнопка «В браузере» — открывает тот же самый поиск на pathofexile.com/trade2.
* Двойной клик по строке копирует шёпот продавцу.
* Соблюдает лимиты запросов GGG (`X-Rate-Limit-*`), чтобы не словить временный бан.

**Итем-фильтр**

* Тянет цены с poe.ninja (PoE2) и раскладывает базы по существующим тир-блокам NeverSink.
* Оформление автора не трогается вообще: меняются **только строки `BaseType`** внутри блоков с тегами `$type->… $tier->tN`. Цвета, звуки, иконки, порядок блоков, комментарии остаются как были.
* Блоки с `StackSize`, `AreaLevel`, `ItemLevel`, `WaystoneTier`, `Quality` не трогаются — это прогрессия и стаки, там своя логика.
* Пороги тиров настраиваются по каждой группе (`currency`, `essences`, `runes`, `soulcores`, …) в экзальтах, дивайнах или хаосе.
* Есть «Предпросмотр» — показывает отчёт и построчный дифф, файл при этом не меняется.
* Перед записью делается бэкап (`%APPDATA%\PoE2Helper\filter-backups`).
* Обновление по кнопке, плюс галочка «обновлять при запуске программы».

## Как получить готовую папку с exe

Сборку делает GitHub — от тебя нужен только аккаунт. Ничего устанавливать на свой ПК не надо.

1. Создай на GitHub новый репозиторий (можно приватный), **без** README и .gitignore.
2. Загрузи туда содержимое этой папки. Самый простой путь — на странице пустого репозитория
   нажать **uploading an existing file** и перетащить все файлы и папки.
   *Важно:* папка `.github` должна попасть в репозиторий — в проводнике Windows скрытые папки
   видны только при включённой галочке «Скрытые элементы». Если перетащить не получается,
   используй `git`:
   ```bash
   git init
   git add .
   git commit -m "PoE2 Helper"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/ТВОЙ_РЕПО.git
   git push -u origin main
   ```
3. Открой вкладку **Actions** в репозитории. Сборка `build-windows` стартует сама после пуша
   (если GitHub попросит подтвердить запуск workflow — согласись). Идёт ~5 минут.
4. Зайди в завершившийся запуск → блок **Artifacts** внизу страницы → скачай `PoE2Helper-windows`.
5. Внутри ZIP — папка `PoE2Helper` с `PoE2Helper.exe`. Распакуй куда угодно и запускай.
   Важно: запускать из распакованной папки, а не изнутри архива.

Хочешь автоматический релиз со ссылкой для скачивания — поставь тег:

```bash
git tag v0.1.0 && git push --tags
```

ZIP появится на странице **Releases**.

### Альтернатива: собрать у себя

Нужен [Python 3.11+](https://www.python.org/downloads/) с галочкой *Add python.exe to PATH*.
Дальше двойной клик по `build.bat` — он сам создаст окружение, поставит зависимости и соберёт
`dist\PoE2Helper\`. Python после сборки больше не нужен.

## Первый запуск

1. Запусти `PoE2Helper.exe`. Откроется окно, в трее появится иконка.
2. На вкладке **Обзор** проверь лигу — она определяется автоматически с poe.ninja.
   Если угадана не та, впиши вручную в **Настройки → Лига**.
3. Дождись строчки «Пул модов: N записей» — это список модов с торговой площадки,
   он качается один раз и кэшируется на неделю.
4. Запусти PoE2 в режиме **«Окно без рамки»** (Fullscreen не даст оверлею показаться поверх).
5. Наведи курсор на предмет и нажми `Ctrl+D`.

Окно можно закрыть — программа останется в трее. Выход — через меню трея.

### Настройка фильтра

1. Вкладка **Итем-фильтр** → выбери свой `.filter`
   (обычно `Документы\My Games\Path of Exile 2\`; найденные файлы показаны списком).
2. Нажми **Считать группы из файла**. Программа прочитает твой фильтр и покажет,
   какие группы `$type->` в нём есть на самом деле и сколько в каждой тиров.
   Это важно: NeverSink переименовывает теги от версии к версии и использует
   вложенные имена вроде `endgame->normalcraft->any`, так что список из настроек
   может не совпасть с твоим файлом. Сними галочки с групп, которые трогать не надо.
3. Нажми **Предпросмотр** — увидишь, что и куда переедет, и дифф. Файл не изменится.
4. Устраивает — жми **Обновить фильтр**.
5. В игре: Настройки → Игра → перезагрузить список фильтров (или перезайти в персонажа).

Галочка **Автоопределение групп** (включена по умолчанию) добавляет к обработке все
группы из файла, где цены известны хотя бы для половины баз — страховка на случай,
если настройки промахнулись мимо новых тегов. Группы, где цен почти нет
(например, базы брони), не трогаются.

Пороги в таблице читаются так: первое число — граница тира t1, второе — t2 и так далее.
Например `40, 10, 3, 1, 0.3, 0.1, 0.03` в экзальтах означает «всё дороже 40 экзов — в t1,
от 10 до 40 — в t2, …». Лишние пороги отбрасываются, недостающие достраиваются делением на 3.
Галочка в первом столбце включает/выключает группу.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Торговая площадка ответила 403» | Cloudflare требует сессию. Зайди на pathofexile.com в браузере, F12 → Application → Cookies → скопируй значение `POESESSID` и вставь в **Настройки → POESESSID**. Этот токен = доступ к аккаунту, никому его не показывай. |
| Хоткей не срабатывает | Либо сочетание занято другой программой (сообщение будет на вкладке «Обзор») — поменяй его в настройках; либо PoE2 запущен от администратора, а хелпер нет — тогда запусти хелпер тоже от администратора. |
| «Игра ничего не скопировала» | Курсор должен стоять ровно на предмете, а игра — быть активным окном в режиме «Окно без рамки». |
| Оверлей не виден поверх игры | Fullscreen (эксклюзивный) не поддерживается ни одним оверлеем. Переключись на «Окно без рамки». |
| Много модов «не найдено в пулe» | Клиент игры должен быть **английский**: моды сопоставляются по английскому тексту. |
| «Слишком много запросов» | Лимиты GGG. Подожди указанное время — программа сама считает окна и обычно до этого не доводит. |
| Группы фильтра пропущены | В твоём фильтре нет блоков с такими тегами `$type->`. Отчёт после «Предпросмотра» перечисляет, что нашлось. Теги есть у фильтров NeverSink/FilterBlade; самописный фильтр без тегов пересчитать нельзя. |

Лог: `%APPDATA%\PoE2Helper\poe2helper.log`.
Настройки: `%APPDATA%\PoE2Helper\config.json`.
Чтобы всё хранилось рядом с exe (портативный режим) — создай пустой файл `portable.txt` в папке с `PoE2Helper.exe`.

## Что внутри

```
src/poe2helper/
  app.py             трей, хоткеи, буфер обмена, склейка всего
  config.py          настройки (JSON) и пороги тиров по умолчанию
  paths.py           %APPDATA%, поиск папки с фильтрами PoE2
  hotkeys.py         RegisterHotKey + SendInput (чистый ctypes)
  parser/item.py     разбор текста предмета из буфера
  parser/stats_db.py пул модов торговой площадки и сопоставление текста
  trade/client.py    /api/trade2/search|fetch, realm poe2
  trade/ratelimit.py скользящие окна по X-Rate-Limit-*
  trade/query.py     сборка JSON-запроса
  trade/ninja.py     экономика PoE2 с poe.ninja
  filters/parse.py   разбор .filter по блокам (без потерь)
  filters/retier.py  перекладывание BaseType между тирами
  filters/update.py  цены → перетиринг → бэкап → запись
  ui/                оверлей, диалог модов, главное окно
tests/               40+ тестов логики + прогон окон вхолостую
```

Тесты: `python -m unittest discover -s tests -v`.
Проверка забытых импортов без запуска: `python tools/check_names.py src`.

## Источники данных

* Торговая площадка: `https://www.pathofexile.com/api/trade2/…` (realm `poe2`) — официальное API.
* Экономика: `https://poe.ninja/poe2/api/economy/…`.

Программа не читает память игры, не автоматизирует ввод в игре и не нарушает ToS GGG:
всё взаимодействие — это `Ctrl+C` по твоей команде и обычные HTTP-запросы.
